1. Introduction and installation

1.1 What SpectraMaster does

SpectraMaster is a gamma spectrum analysis system for the laboratory, for HPGe and NaI detectors. It analyses spectra (peaks, nuclides, activities and concentrations), calibrates them (energy, resolution, efficiency), keeps the analysis as a traceable session and prints the reports. It also converts spectrum files in the style of ORTEC DataMaster (A49-B32), with the same naming rule and the same command line (-i input -j output with the DataMaster format numbers), and its menus, keys and workflow follow Aptec PCMCA/WIN. In detail:

  • Formats: reads 59 spectrum formats (Aptec, ORTEC, Canberra/Genie, IAEA, N42, Excel and many legacy laboratory formats), whatever the file extension, and writes 35 of them. Every written file is read back and any difference is reported.
  • Viewing: a fast plot with zoom history, an overview strip, ROIs, overlays, stepping through the found peaks and image export.
  • Two analysis methods: the Aptec method on regions of interest (peak search, Multifit, identify, background subtract, quantify), and SpectraMaster's fitted-peak analysis with nuclide identification from a library built on IAEA ENSDF data.
  • Calibrations: energy and FWHM calibration from a source, with every line-to-peak assignment shown for review; a calibration drift check; efficiency calibration with independent validation.
  • Activity: activity and concentration (Bq, Bq/kg, Bq/L, Bq/m³) with an uncertainty budget, decision threshold and detection limit (Currie or ISO 11929). Corrections: background, reagent blank, reference peak, true-coincidence summing (gamma-gamma and 511 keV annihilation) and self-attenuation.
  • Traceability: analysis sessions with fingerprints of the files used, an undoable edit history, inspection and manual refit of the peak fits, review, and a JSON report record.
  • Many spectra at once: batch analysis by measurement group, and reports for many files.
  • Archive search across tens of thousands of old spectra (text, nuclides, date, detector).
  • Detector quality control with control charts and Westgard rules (ISO/IEC 17025, 7.7).

The interface is fully bilingual (Arabic and English) and remembers your choices between sessions.

Responsibility. SpectraMaster computes and documents; it does not certify. The results must be reviewed by a qualified analyst and the method validated by the laboratory. The checks against reference data (appendix E) are not a validation or a statement of compliance.

1.2 Installation

SpectraMaster consists of two programs. Python or any other runtime is not needed.

SpectraMaster.exeThe graphical program (windows, plots, analysis, reports). Started with the DataMaster arguments -i in -j out it converts silently without opening a window.
smconvert.exeThe command-line converter and tool box for batch files, scripts and the Windows task scheduler (chapter 4 and appendix B).

Installer (recommended)

  1. Run SpectraMaster_Setup_1.0.0.exe (administrator rights are needed) and choose the language of the setup wizard (English or Arabic).
  2. Accept the license, keep the folder C:\Program Files\SpectraMaster and choose the components: main program, command-line tool smconvert (optionally added to the system PATH), user manuals and sample spectra.
  3. Choose the tasks: desktop icon and the file associations (.s0 .chn .cnf .spe .spc .iec .n42, each can be switched off). Associated files open in SpectraMaster with a double-click; all of them also get Open with › SpectraMaster.

The Start menu group SpectraMaster contains the program, both user manuals, the release notes, the sample spectra folder and the uninstaller. To pin SpectraMaster to the taskbar, right-click its Start-menu entry (or the running program's taskbar button) and choose Pin to taskbar. The licences of all bundled components are in the installation folder (licenses\THIRD_PARTY_NOTICES.txt).

Uninstall with Settings › Apps or the Start-menu entry. The uninstaller asks whether your own data (archive index, efficiency curves, detector profiles, QC tracks in %APPDATA%\SpectraMaster and the settings) should be deleted too; the default answer keeps them. It removes only SpectraMaster's own file associations and PATH entry.

Portable copy

The two programs are also available as single packed executables: copy them into any folder (even a USB stick) and start SpectraMaster.exe; nothing has to be installed. The first start after a reboot can take a few seconds while Windows unpacks the program.

Note. The programs are not code-signed, so Windows SmartScreen may ask for confirmation the first time (More info › Run anyway, after checking with your IT department). If Windows still shows the old icon after an update, restart the computer: Windows keeps icons in a cache.

1.3 First start, splash screen and language

At start-up a splash screen shows the logo, the designer and the version for about 1.5 seconds (click it to close it at once). It can be switched off with Help › Show Splash Screen at Startup.

The program starts in English the first time. Switch the language with View › Language › English / العربية; the whole interface changes at once (including the right-to-left layout) and the choice is remembered. The spectrum plot always runs left to right (low energy on the left) in both languages.

1.4 Windows and dialogs

  • Every window has minimize, maximize and close buttons. A window larger than the screen is fitted to the screen when it opens; if its contents cannot shrink that far, they scroll and the last row of buttons (OK, Calculate, Close …) stays visible below.
  • The calibration windows (Quick Energy, Full Calibration) and Fit Inspection are modal, as in Aptec: while they are open the main window does not respond, so the spectrum cannot change in the middle of a calibration. Batch analysis and batch reports stay modeless because they run for minutes.
  • Long operations run in the background with a busy message (analysis, efficiency measurement, activity calculation, calibration proposal, peak-shape measurement, the analysis before a report), so the window keeps responding.

3. Opening spectra

3.1 Open a spectrum

  1. Choose File › Open › Spectrum… (Ctrl+O) or the Open button.
  2. Select the file. With Show description ticked, the panel on the right shows the detected format, sample ID, description, channels, live/real time, start time and a thumbnail of the spectrum before you open it — useful when browsing archives with cryptic file names.
  3. Click Open. The spectrum is drawn and its details appear in the information panel.

The file filter lists all readable extensions; choose All files (*) for files with unusual extensions — the content is recognised, not the name.

3.2 Input format: auto-detect or fixed

By default the input format is detected automatically from the file content (binary signatures and header keywords), then from the extension. If neither identifies the file, a last stage looks at the content alone with the formats that can be recognised safely that way (ASCII, Channel Data CSV, EML, IAEA ASCII .dat, NPL, Wallac, Laval, JCAC, TKA). A spectrum found this way carries a note in the status bar (format recognised from the content). If several formats fit, the message names them; choose one by hand (a TKA file under another name, for example, cannot be told from one-column ASCII). A file whose channels hold NaN or infinity opens, with a note in the status bar, but peak search and analysis refuse it.

File › Open Input Files As… (Ctrl+I) forces one format, exactly like DataMaster. The choice applies to Open, batch conversion and overlays and is shown in the status bar (Input: …).

Tip. Several formats share an extension (.spc, .dat, .txt, .xml, .s0). Auto-detect distinguishes them by content. Force a format only when auto-detect fails; if a forced format cannot read the file, the error message suggests returning to auto-detect.
Uncalibrated MCA files. Some ORTEC CHN, Canberra CNF and Amptek MCA files store the placeholder calibration E = 0 + 1 × channel. SpectraMaster reads it as no energy calibration; the status bar says so and the stored values are kept in the metadata. Calibrate the spectrum (chapter 8) before identifying nuclides.

3.3 Drag and drop, command line, multi-spectrum files

  • Drop one file on the window to open it; drop a folder to open the Convert Folder dialog; drop several files to open the Convert Files dialog.
  • SpectraMaster.exe file1.S0 opens the file at start-up (also used by "Open with…" in Windows Explorer).
  • Files holding several spectra (e.g. N42, PCF, some CNF) show a selector Spectrum i of n in the information panel.

4. Converting spectra

4.1 Save the displayed spectrum (Save As)

  1. Open the spectrum (chapter 3).
  2. File › Save As… (Ctrl+Shift+S): choose the output format in the list (code, name, extensions) and click OK.
  3. Confirm the file name. The proposed name follows the DataMaster rule (below); the last output folder is remembered.

Warnings appear in the status bar after saving. What a format cannot hold is never changed silently: every written file is read back with the same format and every difference is reported — counts, number of channels, first channel, energies (more than 0.001 keV), live and real time, start time, sample ID, description, detector and FWHM calibration. Formats that can only be written say that they could not be checked. In particular:

  • Negative counts (after a background subtraction or Strip) are refused by the formats that store only non-negative channels (CHN, SPC, CNF, Exploranium, NPL ASCII, SPC ASCII): choose a format that keeps them, e.g. IAEA SPE, N42, JSON or Excel.
  • Fractional counts are rounded in integer formats, with a warning giving the largest change.
  • An unknown acquisition date is reported for formats that always store one; CHN reads its placeholder date back as unknown.
  • Arabic-Indic digits (١٢٣) in the sample ID and description are written as 0–9 in formats that cannot hold them, with a warning.
  • A spectrum with NaN or infinite counts is not written.

4.2 The DataMaster naming rule

The output name is the input name with its extension appended after an underscore, plus the extension of the output format: CHERN.S0 → CHERN_S0.chn. Files with several spectra get a running number: RUN.n42 → RUN_n42_1.spe, RUN_n42_2.spe, … This avoids overwriting when A.S0 and A.CHN are both converted to SPE.

4.3 Converting many files or whole folders

  • File › Open › Select Multiple Files to Convert… (Ctrl+M): pick any number of files.
  • File › Convert Folder… (Ctrl+D): choose a folder, optionally Include sub-folders, then Find Files. With All files (ignore extensions) every file is sniffed by content.

Choose the output format, then the output folder: Same folder as each input file, or one folder — with Keep sub-folder structure the input tree is recreated inside it. Overwrite existing files controls replacement. Click Convert; each line shows OK, the number of outputs, a warning or the error. A failure never stops the batch. Open Output Folder opens Explorer at the result.

Input format in batches. In auto-detect mode only files whose content is recognised (or whose extension belongs to a plain-text format) are converted, so reports, Word files and pictures in the same folder are skipped; recognised spectra are added whatever their extension. With a fixed input format the extension decides, as in DataMaster.

4.4 Command line (smconvert.exe)

DataMaster syntax

smconvert -i InputFile -j OutputFile          (i, j = format codes, i = 0 auto-detects)

smconvert -13 CHERN.S0 -1 "C:\Spectra\Converted Chern.chn"
smconvert -0  SAMPLE.CNF -7 SAMPLE.SPE
SpectraMaster.exe -13 CHERN.S0 -16 CHERN.CNF  (silent, no window; on error the window opens)

The exit code is 0 on success and 1 on failure (2 for wrong arguments), so batch files can test %ERRORLEVEL%. A calibration refit and the read-back differences are printed as warnings.

Modern subcommands

smconvert formats                                   list all formats with codes
smconvert info CHERN.S0                             all metadata of a file
smconvert convert D:\Archive --to n42_2012 -r --out E:\N42 --keep-tree
smconvert convert *.S0 --to chn                     glob patterns are accepted
smconvert convert D:\In --from aptec_s0 --to 7 --no-overwrite -q

--to and --from accept the code (7), the key (iaea_spe) or an alias (spe, chn, cnf). Other subcommands: peaks, identify, calibrate, sum, subtract, rebin, effcal, activity, index, rescue — see the following chapters and appendix B.

Archive rescue. smconvert rescue D:\OldArchive -o E:\Rescued --to n42_2012 --to ci_cnf --resume converts a whole archive, re-reads every output to verify counts and times, writes a log workbook and can be resumed after an interruption. The archive itself is only read. smconvert index ROOT -o catalog.xlsx writes a catalogue of all spectra.

4.5 GammaVision / MAESTRO integration

GammaVision and MAESTRO can call SpectraMaster as their external converter instead of DataMaster. Help › GammaVision / MAESTRO Integration… shows the exact Program and Arguments to enter in GammaVision (File › Settings › Import/Export) with Copy buttons.

$(FullName) and $(FullBase) are GammaVision macros (full path, path without extension). If a conversion fails, SpectraMaster opens its window with the input file and the error message, as DataMaster does.

  • Horizontal drag zooms to the dragged channel range (counts axis automatic); dragging a box zooms both axes.
  • Every zoom is stored in a history: Back (Backspace) and Forward (Alt+→). Reset Zoom (Ctrl+0) or a double click on an empty part of the plot shows the full spectrum.

5.3 Stepping through the found peaks

After an analysis, the found peaks can be visited one by one, as in MAESTRO:

  • Ctrl+← / Ctrl+→ move the marker to the previous / next found peak.
  • Space / Tab (with Shift: back) index the found peaks and wrap around at the ends. When ROIs exist, Space indexes the ROIs first, as in Aptec.
  • A double click on a peak indexes it.

The indexed peak is shown in the status bar (energy, channel, net area ± u and its nuclide, or no library match) and selected in the peaks table. When a nuclide is selected, its library lines are drawn green and solid where a found peak lies at the line, and blue and dashed where none does.

5.4 Go to an energy or channel

Type an energy in the Go to box (Ctrl+G), e.g. 661.66, and press Enter. The unit box selects keV or channel; the width box selects ±3/5/10 FWHM (from the FWHM calibration or the detector model) or ±5…100 keV. Uncalibrated spectra accept channels only.

5.5 Counts axis and energy axis

The counts axis can be Linear, Log or √ (square root) (Ctrl+L toggles linear/log). Auto Y fits the counts axis to the visible part. Energy (Ctrl+E) switches the horizontal axis between keV and channel (keV only for calibrated spectra).

5.6 Regions of interest (ROI)

Paint an ROI with F3 or Ctrl+click left then right of the peak, or let Peak Search (P) set them. The Regions of Interest panel lists start, end, centroid, energy, FWHM (channels and keV), gross, background and net area with ±1σ, % error, net count rate and flags, then isotope, activity and MDA after Identify and Quantify. The background follows Aptec's rules, from end points outside the ROI (ROI Properties, Shift+R). Delete with Del, Delete or Clear All; Export CSV… saves the table. Details in section 7.3.

5.7 Overlays

Overlay (Ctrl+Shift+O) draws other spectra — typically the background or a previous measurement — over the displayed one, each in its own colour with a legend. View › More View Options › Overlays › Normalize Overlays to Live Time scales each overlay by LTdisplayed/LToverlay (the factor is shown in the legend). Overlays of different calibration are aligned in energy. Remove them one by one or all at once from the right-click menu.

5.8 Exporting the plot

Export (Ctrl+Shift+E) saves the current view as a PNG image or as an SVG vector drawing (for reports and publications); Ctrl+Shift+C copies it to the clipboard for Word or PowerPoint.

6. SpectraMaster analysis: fitted peaks and nuclide identification

6.1 Running the analysis

This analysis is the alternative to the Aptec method (chapter 7). Choose it in Analyze › Setup › Analysis Method › SpectraMaster, then press P (Analyze › Peak Search) or the Analyze button. The analysis runs in the background (a few seconds for an 8k HPGe spectrum) and opens the Analysis Results panel. Analyze › Auto-analyze on Open analyses every spectrum as soon as it is opened.

6.2 The peaks table

For each peak: energy (keV), centroid (channel), FWHM (keV), net area ± 1σ, count rate (cps), significance (net area / its uncertainty) and the assigned nuclide. A double click zooms to the peak. Notes mark special peaks: X-ray region, annihilation (511 keV), single / double escape, sum peak (e.g. 1173+1332), possible backscatter.

How it works, in brief:

  • Width model. The FWHM model comes from the FWHM calibration (or the energy calibration and a detector-type guess) and is rescaled to the strongest isolated peaks. For HPGe without a FWHM calibration its energy dependence is corrected too, between the lowest and highest of those peaks.
  • Implausible width model. If the free-width fits of the strongest peaks show that the model is about twice or half the real width (for example a stored FWHM calibration of one channel, or a wrong detector guess), the model is scaled by 2 or ½ before the search and a note says so (FWHM model implausible).
  • Search and fit. Peaks are searched with a Gaussian matched filter (second-difference method) and accepted above a significance of 3. Neighbouring peaks are fitted together as multiplets (Gaussians + background + step); areas and uncertainties come from the fit covariance. HPGe peaks sit on a straight background; scintillator (NaI) peaks on a log-quadratic continuum whose curvature is measured on a wider region that stops before the neighbouring peaks. When the detector's peak shape was measured (section 6.6), peaks are fitted with its low-energy tail.
  • Spectra that are not Poisson counts. If the spectrum was already background subtracted, stripped, normalized or smoothed, a note in the results says that the uncertainties are not valid.

6.3 The nuclides table and the confidence value

Each candidate nuclide shows its confidence, half-life, category (natural, fission, activation, calibration, medical, industrial, actinide; nuclides with two common origins show both, e.g. Cs-137 "fission / calibration"), the number of lines found / expected and a note (series membership, "typical background", interferences such as U-235 185.7 keV under Ra-226 186.2 keV). Selecting a nuclide marks all its library lines on the plot (section 5.3).

The confidence is a heuristic score (0–100 %), not a probability. It combines how much of the expected (detectable) line pattern is explained, the energy agreement, the statistical significance, penalties for a missing strongest line or inconsistent area ratios, and a greedy treatment of shared peaks. Weak lines below the local detection limit are not counted as missing. Results — especially low-confidence ones, single-line nuclides and short-lived nuclides in old spectra — must be reviewed by an expert. The identification does not replace the laboratory's validated analysis procedure.

Sampling date. When the session's sample information has a sampling date (end, else start; section 9.7), a nuclide that has decayed by more than 10 half-lives between sampling and the start of the measurement (less than 0.1 % left) gets a low plausibility; if it is still listed, its note says how many half-lives have elapsed. Natural-series members and a daughter whose parent is still present (Tc-99m with Mo-99) are not affected. Run the analysis again after entering the sample information. Radiopharmaceuticals (Mo-99, Tc-99m, F-18, Ga-67, I-123 …) are treated as common nuclides only with the medical library. A nuclide found from one line only, although it has other lines in the spectrum's range, carries the note one line matched … confirm.

Peak labels (Ctrl+Shift+L) write the nuclide names on the plot; Export… in the results panel saves peaks, nuclides and spectrum details to Excel or CSV.

6.4 Uncalibrated spectra

Without an energy calibration peaks are listed by channel only and no nuclide is identified (a message explains this). Calibrate the spectrum first (chapter 8), e.g. with Eu-152 or Co-60/Cs-137 lines.

6.5 The nuclide library

The built-in library contains 200 nuclides with 2,719 gamma and X-ray lines. Values are taken from the IAEA ENSDF evaluation (IAEA ndlab database behind LiveChart of Nuclides) and cross-checked against Sandia National Laboratories' SandiaDecay and the LNHB/DDEP recommended data. Lines that duplicated another evaluation were removed and lines lost from daughters restored; where IAEA and two other evaluations disagree, the DDEP value is used (for example Ac-228 674.75 keV: 0.105 %). Short-lived daughters in equilibrium (Ba-137m, Pr-144, Rh-106, La-140 …) are included in the parent's intensities; natural-series members are separate entries. On the command line another library can be used: smconvert identify FILE --lib mylib.csv with lines nuclide, energy_keV, intensity_%[, half_life, category].

Limitations

  • The identification does not correct true-coincidence summing and uses no detailed efficiency model: the expected line ratios use a generic HPGe/NaI efficiency shape. (The activity calculation can correct summing, section 9.5.)
  • Strongly overlapping multiplets and very low-statistics spectra can give false or missed identifications.
  • Decay since the measurement is not considered: a nuclide is proposed if its lines are present, even if it is implausible for the sample history.

6.6 Detector profiles, peak shape and analysis sessions

The Workflow panel (View › More View Options › Workflow Status) shows the analysis session of the displayed spectrum: its detector, geometry, calibrations and the status of each step, coloured by level. Detectors… opens the detector profiles; Edit… describes the sample geometry. A profile keeps a permanent id, so renaming a detector keeps its calibrations and sessions. Choosing the detector of a measurement is an undoable edit, and an efficiency calibration of another detector is then reported as incompatible.

Peak Shape… in the detector profiles measures the low-energy tail of that detector's peaks from calibration spectra with strong, well separated peaks. The spectra are read and measured in the background (Measuring the peak shape …); you confirm the result before it is recorded. From then on, the analysis of that detector's samples fits peaks with this shape. Without it, peaks are Gaussian.

File › Save Session stores the session (.smsession): the spectrum reference with its SHA-256 fingerprint, the calibrations, the background and reagent blank files with their fingerprints, the coincidence table used, the results, the review and the edit history. When a session is opened, the spectrum file is checked against the fingerprint. Results computed by an older analysis engine are shown as stored and marked as requiring recalculation; the engine version is shown in Help › About.

6.7 Fit inspection and manual refit

Analyze › Fit Inspection / Manual Refit… shows how every peak was fitted and lets you correct a fit, with every change recorded.

  • Fitted regions (left): each region with its energy, number of peaks and χ²/ν. Regions with a poor fit or a warning are coloured. The plot shows the data with error bars, the fit, its components and the background, and the residuals in units of σ.
  • Tabs: Region details (χ²/ν, width scale, step height, engine warnings), Components (centroid, energy, FWHM, net area, whether it is reported and why not), Discarded components (all regions) and Before / after the last edit (change of centroid and area in units of σ).
  • Manual editing: choose a region (or Use Selected Region), the peak positions (fixed or free), the width (free ×0.5–2 of the model, held at the model, or a fixed multiple) and the step background, give a reason, then Refit Region. Add Peak at Channel and Remove Selected Peak… refit the neighbours. Undo / Redo step through the edits; Re-run Automatic Fit starts again (the edits stay in the edit log).
  • The edited peaks are used by the activity calculation. A background-subtracted spectrum is refitted with its propagated variance (sample + k² × background), so its negative channels are kept and the uncertainties stay valid.

7.4 Analyze menu

Setup ›

ROI Properties (Shift+R), Peak Search (Shift+P), Multifit (Shift+M), Identification (Shift+I), Background Subtract (Shift+B), Quantify (Shift+Q), Analyze Defaults (factory defaults, or save and recall your own defaults for all of them at once) and Analysis Method (Aptec or SpectraMaster).

Peak Search (P)

Sets ROIs on the peaks, rejects every ROI whose 1-sigma net error is above the Max Peak Error and recalculates the backgrounds until the result is stable; the search can be limited to a channel range (Partial). Note: the search follows the Aptec help but does not reproduce Aptec's ROIs exactly: it finds about 79 % of them (section 7.8). Always review the ROIs and add or delete with F3 and Del.

Multifit (M)

Decomposes each ROI into Gaussian peaks by Marquardt-Levenberg least squares. An ROI is a multiplet when it is wider than the resolution calibration expects or shows several significant centroids. The width is fixed from the resolution calibration (or varying) and varies automatically when 511 keV lies in the ROI; the background is fixed from the end points (or varying). A peak is kept when its amplitude ≥ K × its uncertainty (K = 1.645). Without a resolution calibration one is made from the ROI widths. Each fitted peak becomes its own ROI, flagged m (a fitted singlet s), so Identify and Quantify use the separated peaks; each Gaussian and their sum are drawn. Changing the ROI Properties removes the fits.

Identify Peaks (I)

With an Aptec library (isotope.lib) or SpectraMaster's bundled library. Library lines within the tolerance of the ROI centroid energy are candidates: a fraction of the ROI FWHM (default 0.5) or a fixed tolerance in keV. An isotope is accepted when its lines with an ROI carry at least the Fraction Limit (%) of the yield of all its lines inside the spectrum's energy range. Isotopes decayed beyond the Half Life Limit can be rejected.

Background Subtract (B)

Choose the background spectrum in Shift+B. It is searched and identified with the same setups, and the net count rate of the same isotope line is subtracted when it is above its MDA; uncertainties are combined in quadrature (flag b). No background-subtracted Aptec file was available to compare with.

Quantify (Q)

Activity = net rate / (efficiency × yield), decay-corrected from the count start to the activity time (F6) and converted to the chosen units; as activity in the sample, concentration (divided by the quantity) or total activity (concentration × total quantity), multiplied by the W/X/Y constants when selected. Emission units (gamma/s) are not divided by the yield. The efficiency comes from the spectrum's efficiency calibration or a saved curve, at the ROI centroid energy as Aptec does.

8. Energy calibration, drift check and spectrum arithmetic

The input files are never modified: a calibration is applied to the displayed spectrum (saved only with File › Save As or in the session), and the command-line tools write new files.

8.1 Energy and FWHM calibration from a source

Setup › Advanced Calibration Tools › Energy Calibration… proposes a calibration from the lines of a known source in the displayed spectrum.

  1. Type the calibration source: one nuclide (Eu-152), several (Co-60,Cs-137), mixed or background (natural lines). Choose the polynomial order (Auto (F-test) or 1–3) and press Propose. The search runs in the background.
  2. Review every line-to-peak assignment: library energy, channel ± its uncertainty, residual, the leave-one-out residual (the line predicted by a fit without it) and the significance. Untick a wrong assignment and give the reason for exclusion; the calibration is refitted.
  3. Read the validation: number of points, order, F-test, χ²/ν, the calibrated range and how much of the spectrum lies outside it, with errors and warnings in the engine's words. Accept and Apply is disabled while there are errors.
  4. Optionally tick Also apply the FWHM calibration proposed with it. The FWHM calibration is fitted through the measured widths of the lines (each line fitted with a free width, its neighbours together): the 511 keV annihilation line is left out, outliers more than 10 % off are removed, and a second order is used only if it rises with energy. Fewer than two measured widths give no FWHM calibration.
  5. Accept and Apply. Nothing is changed before this step.

8.2 Calibration drift check

Setup › Advanced Calibration Tools › Check Calibration Drift… measures the energies of reference lines in the displayed spectrum and compares them with the current calibration. Empty reference lines mean the natural background lines (K-40, U and Th series), which every long measurement contains.

The result gives the gain and offset change, the largest shift in keV, in FWHM and in σ, the lines excluded and why, and the current and proposed coefficients. Apply Proposed Correction… replaces the energy calibration of the displayed spectrum after a confirmation, which says so when no significant drift was found; the change is recorded in the spectrum's calibration note. Apply it only when the drift is significant.

9. Efficiency calibration and activity

Before you start. The efficiency curve is valid only for the same detector, geometry (container, filling height, distance) and matrix density as the standard. True-coincidence summing (TCS) is corrected only when you enable it and give the peak-to-total ratio of your detector and geometry (section 9.5); otherwise cascade emitters such as Co-60, Cs-134, Y-88 and Eu-152 are flagged. A density different from the standard's is corrected only on request (section 9.6). Results must be validated by the laboratory.

9.1 Efficiency calibration

Setup › Advanced Calibration Tools › Efficiency Calibration… works in four tabs.

  1. 1. Certificate. Open the standard spectrum (here QCY48CAL.S0, 10 ml bottle at 10 cm, HPGe) or Use displayed spectrum; optionally a background spectrum. One row per nuclide: activity (Bq), uncertainty %, reference date, half-life (s) and optionally the lines keV:yield% (empty = library values). Fill it from the Aptec records (the source records stored in Aptec .S0 files), a Preset (QCY48, QCRB1241, Eu-152 point source), Import CSV… or by typing. A common standard uncertainty shared by all nuclides (e.g. gravimetric preparation) can be given once.
  2. 2. Detector and geometry. The detector profile and the geometry of the standard: kind (Marinelli, point source, cylinder / bottle, air filter), container, volumes, diameters, fill height, matrix, density, distance to the end cap, filter dimensions and position. Unknown values stay empty — they are never taken as zero. The geometry is stored with the curve and checked against the sample when activities are calculated.
  3. 3. Points and model. Choose the model: two-branch log-log (recommended for HPGe: low- and high-energy branches joined at a crossover energy) or a single log-log polynomial; orders and crossover Auto (cross-validation) or explicit. Click Measure & Fit: each line becomes a point (net area, efficiency, uncertainty, fitted value, residual). With a background spectrum the peaks are fitted on sample − k × background with its propagated variance. Untick Use for a doubtful point (a reason is asked and recorded) and press Refit; Add manual point adds a point by hand. Amber rows are cascade emitters (section 9.5).
  4. 4. Independent validation. Measure a second source that was not used in the fit, with the same detector and geometry: Measure and compare lists measured and curve efficiency, deviation and z for each line. Only when the check is consistent can the curve be Marked as validated (with a note: who, which source, reference). The activity dialog shows whether the curve used is validated.
  5. Check χ²/ν and the residual plot (points should scatter within their error bars), then Save curve… The curve (JSON) is stored in %APPDATA%\SpectraMaster\efficiency\ and appears in the activity dialog.

Point efficiency: ε = N / (tlive · A(t0) · C · I), with the activity decay-corrected from the reference date to the start of counting and C the decay during counting. The curve uncertainty combines the fit covariance (scaled by χ²/ν when > 1), the part of the certificate uncertainty common to all lines and a model error from leave-one-out fits. A single outlying point is limited to 3 times the curve's scatter in this model error and named in the curve warnings, so it cannot inflate every result.

9.2 Activity calculation

  1. Open the sample spectrum (calibrated in energy) and choose Analyze › Activity Calculation….
  2. Select the efficiency curve (its validation status and geometry are shown). Optionally load a background spectrum: peak by peak or full spectrum.   3. Enter the sample quantity and unit (kg, g, L, mL) with its uncertainty, and the reference date (sampling date; default = acquisition start). All activities are decay-corrected to this date.

9.3 Reagent blank

A reagent blank is a blank sample prepared and counted like the samples, with the same reagents, container and geometry. Choose its spectrum in Reagent blank. It is analysed exactly like the sample, with the same curve, options and background, and its activity is subtracted line by line. The blank's uncertainty, including the part of its reference-peak correction it shares with the sample, is in the budget, and the decision threshold includes it. A blank analysed with other options (attenuation, summing correction, reference peak, background) is reported in the notes. The spectrum, background, blank and peaks are taken as they are when Calculate is pressed. The session and the report record the blank file with its SHA-256 fingerprint.

9.4 Reference peak correction

The live time corrects dead time but not every loss: random summing and pile-up remove counts from every peak. A reference peak, from a pulser or a fixed reference source counted with every sample, measures this loss. Each result is multiplied by K = expected rate / measured rate of that peak in the sample spectrum.

  • Enter the peak energy and its expected rate (counts per live second) with its uncertainty. Measure from a spectrum… takes the rate from a low-rate reference measurement, and its date becomes the rate date.
  • For a radioactive reference source, give its half-life in days so the expected rate is decay corrected. Use 0 for a pulser.
  • The peak is measured in the measured sample spectrum (before any background subtraction), as its expected rate is, so a pulser or source also present in the background is still found.
  • If the peak is not found, the calculation is refused. The reagent blank, when given, is corrected the same way.

9.5 True-coincidence summing correction

Nuclides that emit several photons in cascade (Co-60, Cs-134, Bi-214, Y-88, Ba-133, Eu-152 …) lose counts from their peaks when two photons are detected together; positron emitters (Na-22, Co-58 …) also lose counts by summing with the 511 keV annihilation photons. Some lines gain counts this way. The loss grows as the source gets closer to the detector. With True-coincidence summing correction enabled, each line of a cascade emitter is divided by its first-order coincidence summing factor (COI), computed from coincidence data and the efficiency curve.

  • Coincidence data. The probabilities come from the ENSDF decay schemes of the IAEA (LiveChart of Nuclides): for each pair of gamma rays, the probability that the second follows the first in the same decay, from the level scheme with the conversion coefficients, isomers ending the cascade; and for each gamma the probability that a positron (two 511 keV photons) comes with it. They were checked against an independent simulation of the decays (appendix E). Short-lived daughters folded into a nuclide (Bi-207 → Pb-207m, Ce-144 → Pr-144 …) are included.
  • Peak-to-total. The total efficiency is the peak efficiency divided by the peak-to-total ratio PT(E) = min(1, a·(E / 1000 keV)b). PT depends on the detector and the geometry. The values shown are assumptions; enter those of your detector, measured with single-line sources or taken from a detector model. Their uncertainty (default 10 %) is propagated.
  • The calibration curve. If the efficiency curve was measured with cascade emitters in the same geometry (for example a mixed standard with Ba-133 and Y-88), its points already contain summing losses. They are corrected with the same PT and the curve is refitted until it no longer changes; an automatically chosen model (orders, crossover) is chosen again on the corrected points. A curve without points (an imported Aptec ln-ln polynomial) is refused unless you declare it free of summing; the declaration is recorded in the notes.
  • Limits. A line that the coincidence data do not describe is not corrected, and the note says why. A partner photon far below the calibrated range (under 0.8 × its lowest energy) is left out and reported. A line whose first-order factor is outside its validity gives no result; a summing-out loss above 10 % is noted, because the first-order correction degrades in very close geometries.
  • Not included: X-ray – gamma summing (EC nuclides such as Ba-133 and Eu-152; it matters only with an efficiency curve that reaches the K X-ray energies, 30–50 keV) and angular correlation. The session records the coincidence table with its SHA-256 fingerprint.

Command line: --tcs-pt A,B, --tcs-pt-unc and --tcs-curve-summing-free; --blank FILE; --ref-peak keV --ref-rate cps (or --ref-spectrum FILE, --ref-half-life s).

9.6 Self-attenuation

A sample denser than the calibration standard absorbs more of its own gamma rays, mostly at low energies.

  • In the activity dialog a single manual factor (default 1.000) multiplies every result; enter it from your own determination.
  • On the command line an energy-dependent correction is computed from the NIST mass attenuation coefficients (SRD 126) for a slab of the sample and of the standard: --self-att-matrix and --self-att-density (sample), --cal-matrix and --cal-density (standard), --self-att-height-mm (sample height) and --self-att-unc (model uncertainty, %). Matrices: water, organic (resins, organic matter) and mineral (soil, concrete). The factor of every line is recorded, and its uncertainty enters the budget. With true-coincidence summing, the summing of the sample is computed with its self-attenuated efficiency.
smconvert activity SAMPLE.chn --eff curve.json --self-att-matrix organic --self-att-density 1.6 ^
          --cal-matrix organic --cal-density 1.15 --self-att-height-mm 35
The slab model is an approximation; the matrices differ by up to 1.5 % below 100 keV (mineral against organic). Choose the matrix that matches the sample. The manual factor and the energy-dependent model correct the same effect: the program refuses both together.

9.7 Sample information and concentrations

In Sample information, choose the matrix (soil / sediment, water, food, air filter, other) and the unit to report: Bq, Bq/kg, Bq/L or Bq/m³.

  • Bq/kg needs the mass and its basis (dry or wet). Bq/L needs the volume.
  • Bq/m³ needs the air volume, either given directly or as flow rate × sampling duration. It also uses the measured fraction of the filter and the collection efficiency. The collection efficiency is an assumption, so state its source.
  • An empty field means unknown: it is never taken as zero or one. A missing value is listed instead of a concentration.
  • Non-detects are shown as < MDA, never as zero.

10.5 Batch analysis

Analyze › Batch Analysis… analyses many spectra with the same setup, safely.

  1. Add Files… or Add Folder…, then Read and Group. The spectra are grouped by detector, number of channels and energy calibration (within the energy tolerance); unreadable files are listed apart.
  2. Select a group and give its setup: efficiency curve (none = identification only), sample geometry (JSON), identification library and the nuclides to quantify. Assign to Group. No calibration is applied automatically: a group without a setup is reported as not analysed.
  3. Run. The analysis runs in the background with progress and Cancel; the table gives, per file and nuclide, identification, activity, uncertainty, MDA, decision and notes. Save CSV… writes the table.

11. Archive search

File › Archive Search… (Ctrl+Shift+F) finds spectra in large archives — by sample name, words in the description, nuclides found, date, detector, folder or live time — without moving or changing the original files.

11.1 Building and updating the index

  1. Add folder… for each archive root (local disk or network share).
  2. Click Build / update index. The program lists the files, reads the metadata of every spectrum and then analyses each unique spectrum (peak search + identification) in parallel. Progress and the remaining time are shown; Cancel stops safely and the next build resumes.
  3. Later builds only process new or changed files and drop deleted ones, so updating is quick.

12. Detector quality control

Tools › Detector QC… keeps control charts of the check-source and background measurements of each detector, as required by ISO/IEC 17025 (7.7). For every measurement it records the centroid energy (gain/offset drift), the FWHM (resolution), the net count rate decay-corrected to a reference date (efficiency stability), the background rate in an energy window, and live/dead time.

12.1 Creating a QC track

A track is one detector + one check source (or a background measurement). Click New… and fill in:

  • name, detector, detector type (HPGe, NaI, LaBr3, CZT), type (check source / background);
  • monitored lines — from a preset (Cs-137, Co-60, Cs-137 + Co-60, Eu-152, Ba-133, Am-241, Na-22, Background) or typed as keV[:nuclide[:FWHM max]], e.g. 661.657:Cs-137, 1332.492:Co-60:2.0;
  • reference date and reference activity (for decay correction), peak match tolerance;
  • centroid energy from each file's calibration, or a fixed reference calibration — the latter shows real gain drift even when each spectrum was recalibrated;
  • background window, baseline (first N points or a period), the Westgard rules to apply and fixed tolerances (centroid ± keV, rate ± %, background ± %).

12.2 Adding measurements

Add Files…, Add Folder… (e.g. the whole year's QC folder) or Add Displayed Spectrum. Each spectrum is analysed once and its peak list stored, so lines and tolerances can be changed later without re-reading the files; duplicates are ignored. Re-analyse re-reads all source files. In the Measurements table a right click can exclude a point from the statistics (with a note, e.g. "source repositioned"), remove it, or show the spectrum in the main window.

13. Troubleshooting and FAQ

The file is not recognised ("cannot recognise the format")

Check that the file is a spectrum (not a report or a calibration file) and not empty. Try File › Open Input Files As… with the expected format; the smconvert info FILE --from CODE command shows the reader's exact error. If Auto-detect is not active, a wrong fixed format is the most common cause — the status bar shows the active input mode. If the message names several possible formats, choose the right one by hand.

Peaks are at the wrong energies, or no nuclide is identified

  • The file may be uncalibrated or carry an old calibration: check Energy Calibration in the information panel and recalibrate (chapter 8). CHN, CNF and Amptek files with the placeholder E = channel are read as uncalibrated (section 3.2).
  • After a long measurement or a change of the electronics, run the drift check (section 8.2).
  • After conversion to CHN/CNF/SPC, read the refit warning: the deviation of the refitted calibration is printed.
  • Genie-2000 shows channel numbers one higher than SpectraMaster — energies are the same.

Very few peaks are found, or peaks are split in two

The width model may be wrong (a FWHM calibration from another detector, or of one channel). Look for the note FWHM model implausible; recalibrate the FWHM from a source (section 8.1), which fits the measured widths, and inspect the fits (section 6.7).

"uncertainties are not valid" / "not Poisson"

The spectrum was already background subtracted, stripped, normalized or smoothed. Open the measured spectrum and give the background in the activity dialog instead.

The main window does not respond

A modal window (Quick Energy, Full Calibration, Fit Inspection) is open, perhaps behind another window: finish or cancel it. Long calculations show a busy message and keep the window responsive.

A window is larger than my screen

Windows are fitted to the screen when they open; scroll the contents. The buttons of the last row stay visible. Maximize with the title-bar button or a double click on the title.

Arabic sample names became "????" in Genie or MAESTRO

CNF, CHN and SPC store only Latin text (section 3.4). Keep the Aptec S0, SPE, N42 or Excel file as the reference copy. Saving or converting to a format that stores only ASCII text (CHN, SPC, CNF, S100, ND66) prints a warning when the sample ID, description or detector contains Arabic (non-ASCII) characters.

"stores only 3 calibration terms: energy calibration refitted"

Not an error: the target format cannot hold the source polynomial. Accept small deviations (≲ 0.05 keV); for larger ones choose a format that keeps the full calibration (Aptec S0, IAEA SPE, N42, JSON, Excel).

"The peak-search engine is not available" / P is disabled

No spectrum is open, the spectrum is empty, or (SpectraMaster method) the analysis engine is missing. Nuclides are not identified in uncalibrated spectra.

GammaVision does not call SpectraMaster

Copy Program and Arguments again from Help › GammaVision / MAESTRO Integration…; put quotes around paths with spaces when not using the macros.

Where are settings and data stored?

PreferencesLanguage, last folders, input/output formats, window layout, view options and report templates: Windows registry HKEY_CURRENT_USER\Software\SpectraMaster\SpectraMaster.
Archive index%APPDATA%\SpectraMaster\archive.sqlite (changeable in the window).
