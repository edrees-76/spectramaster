1. Introduction and installation

1.1 What SpectraMaster does

SpectraMaster is a gamma-spectrum file converter, viewer and analysis tool for the laboratory. It works in the style of ORTEC DataMaster (A49-B32): the same "open – choose output format – save" workflow, the same output-file naming rule and the same command line (-i input -j output with the DataMaster format numbers). On top of that it offers:

  • reading of 59 spectrum formats (Aptec, ORTEC, Canberra/Genie, IAEA, N42, Excel, many legacy lab formats) and writing of 35 of them, one file at a time or whole folder trees;
  • a fast interactive spectrum plot (zoom, history, overview strip, ROIs, overlays, image export);
  • automatic peak search and nuclide identification with a library built from IAEA ENSDF data;
  • energy recalibration, spectrum sum / background subtraction / rebinning (command line);
  • efficiency calibration and activity calculation (Bq, Bq/kg, uncertainty budget, MDA after Currie or ISO 11929);
  • printed and PDF reports with templates, also for many files at once;
  • archive search across tens of thousands of old spectra (text, nuclides, date, detector);
  • detector quality control with control charts and Westgard rules (ISO/IEC 17025, 7.7).

The interface is fully bilingual (Arabic and English) and remembers your choices between sessions.

1.2 Installation

SpectraMaster consists of two programs. Python or any other runtime is not needed.

SpectraMaster.exeThe graphical program (windows, plots, analysis, reports). Started with the DataMaster arguments -i in -j out it converts silently without opening a window.
smconvert.exeThe command-line converter and tool box for batch files, scripts and the Windows task scheduler (chapter 4 and appendix B).

Installer (recommended)

  1. Run SpectraMaster_Setup_1.0.0.exe (administrator rights are needed) and choose the language of the setup wizard (English or Arabic).
  2. Accept the license, keep the folder C:\Program Files\SpectraMaster and choose the components: main program, command-line tool smconvert (optionally added to the system PATH), user manuals and sample spectra.
  3. Choose the tasks: desktop icon and the file associations (.s0 .chn .cnf .spe .spc .iec .n42, each can be switched off). Associated files open in SpectraMaster with a double-click; all of them also get Open with › SpectraMaster.

The Start menu group SpectraMaster contains the program, both user manuals, the release notes, the sample spectra folder and the uninstaller. To pin SpectraMaster to the taskbar, right-click its Start-menu entry (or the running program's taskbar button) and choose Pin to taskbar.

Uninstall with Settings › Apps or the Start-menu entry. The uninstaller asks whether your own data (archive index, efficiency curves, QC tracks in %APPDATA%\SpectraMaster and the settings) should be deleted too; the default answer keeps them. It removes only SpectraMaster's own file associations and PATH entry.

Portable copy

The two programs are also available as single packed executables: copy them into any folder (even a USB stick) and start SpectraMaster.exe; nothing has to be installed. The first start after a reboot can take a few seconds while Windows unpacks the program.

Note. The programs are not code-signed, so Windows SmartScreen may ask for confirmation the first time (More info › Run anyway, after checking with your IT department).

3. Opening spectra

3.1 Open a spectrum

  1. Choose File › Open › Spectrum… (Ctrl+O) or the Open button.
  2. Select the file. With Show description ticked, the panel on the right shows the detected format, sample ID, description, channels, live/real time, start time and a thumbnail of the spectrum before you open it — useful when browsing archives with cryptic file names.
  3. Click Open. The spectrum is drawn and its details appear in the information panel.

The file filter lists all readable extensions; choose All files (*) for files with unusual extensions — the content is recognised, not the name.

3.2 Input format: auto-detect or fixed

By default the input format is detected automatically from the file content (binary signatures and header keywords), then from the extension. File › Open Input Files As… (Ctrl+I) lets you force one format, exactly like DataMaster. The choice applies to Open, batch conversion and overlays and is shown in the status bar (Input: …).

Tip. Several formats share an extension (.spc, .dat, .txt, .xml, .s0). Auto-detect distinguishes them by content. Force a format only when auto-detect fails; if a forced format cannot read the file, the error message suggests returning to auto-detect.

3.3 Drag and drop, command line, multi-spectrum files

  • Drop one file on the window to open it; drop a folder to open the Convert Folder dialog; drop several files to open the Convert Files dialog.
  • SpectraMaster.exe file1.S0 opens the file at start-up (also used by "Open with…" in Windows Explorer).
  • Files holding several spectra (e.g. N42, PCF, some CNF) show a selector Spectrum i of n in the information panel.

3.4 Supported formats

The complete table with codes is in appendix A and in Help › About SpectraMaster. The most used ones in our laboratory:

Calibration terms. Some formats store fewer energy-calibration coefficients than the source (e.g. CHN, SPC, CNF, S100 keep 3 terms; Laval and Norland 2). SpectraMaster then refits the calibration by least squares over the stored channels and warns: … stores only 3 calibration terms: energy calibration refitted (max deviation 0.206 keV). Check the deviation: a few hundredths of a keV are harmless, larger values (cubic terms on 8k spectra) may shift high-energy peaks. The original coefficients are kept in the metadata (original_energy_coeffs) of formats that store metadata.
Arabic text in CNF, CHN and SPC. These binary formats store sample ID and description as 8-bit Latin text. Arabic letters become ? (CNF, CHN) or are dropped (integer SPC) — without a warning. Use Latin sample IDs for files destined to Genie-2000 / MAESTRO, or keep an Aptec S0, IAEA SPE, N42, JSON or Excel copy, which preserve Arabic text.
Genie channel numbering. Genie-2000 numbers channels from 1, SpectraMaster (like ORTEC and Aptec) from 0. The calibration polynomial is shifted automatically on reading and writing CNF, so peak energies are identical in both programs; only the channel numbers differ by one.

4. Converting spectra

4.1 Save the displayed spectrum (Save As)

  1. Open the spectrum (chapter 3).
  2. File › Save As… (Ctrl+S): choose the output format in the list (code, name, extensions) and click OK.
  3. Confirm the file name. The proposed name follows the DataMaster rule (below); the last output folder is remembered.

Warnings (for example a refitted calibration) appear in the status bar after saving.

4.2 The DataMaster naming rule

The output name is the input name with its extension appended after an underscore, plus the extension of the output format: CHERN.S0 → CHERN_S0.chn. Files with several spectra get a running number: RUN.n42 → RUN_n42_1.spe, RUN_n42_2.spe, … This avoids overwriting when A.S0 and A.CHN are both converted to SPE.

4.3 Converting many files or whole folders

  • File › Open › Select Multiple Files to Convert… (Ctrl+M): pick any number of files.
  • File › Convert Folder… (Ctrl+D): choose a folder, optionally Include sub-folders, then Find Files. With All files (ignore extensions) every file is sniffed by content.

Choose the output format, then the output folder: Same folder as each input file, or one folder — with Keep sub-folder structure the input tree is recreated inside it. Overwrite existing files controls replacement. Click Convert; each line shows OK, the number of outputs, a warning or the error. A failure never stops the batch. Open Output Folder opens Explorer at the result.

Input format in batches. In auto-detect mode only files whose content is recognised (or whose extension belongs to a plain-text format) are converted, so reports, Word files and pictures in the same folder are skipped. With a fixed input format the extension decides, as in DataMaster.

4.4 Command line (smconvert.exe)

DataMaster syntax

smconvert -i InputFile -j OutputFile          (i, j = format codes, i = 0 auto-detects)

smconvert -13 CHERN.S0 -1 "C:\Spectra\Converted Chern.chn"
smconvert -0  SAMPLE.CNF -7 SAMPLE.SPE
SpectraMaster.exe -13 CHERN.S0 -16 CHERN.CNF  (silent, no window; on error the window opens)

The exit code is 0 on success and 1 on failure (2 for wrong arguments), so batch files can test %ERRORLEVEL%. A calibration refit is printed as a warning.

Modern subcommands

smconvert formats                                   list all formats with codes
smconvert info CHERN.S0                             all metadata of a file
smconvert convert D:\Archive --to n42_2012 -r --out E:\N42 --keep-tree
smconvert convert *.S0 --to chn                     glob patterns are accepted
smconvert convert D:\In --from aptec_s0 --to 7 --no-overwrite -q

--to and --from accept the code (7), the key (iaea_spe) or an alias (spe, chn, cnf). Other subcommands: peaks, identify, calibrate, sum, subtract, rebin, effcal, activity, index, rescue — see the following chapters and appendix B.

Archive rescue. smconvert rescue D:\OldArchive -o E:\Rescued --to n42_2012 --to ci_cnf --resume converts a whole archive, re-reads every output to verify counts and times, writes a log workbook and can be resumed after an interruption. The archive itself is only read. smconvert index ROOT -o catalog.xlsx writes a catalogue of all spectra.

4.5 GammaVision / MAESTRO integration

GammaVision and MAESTRO can call SpectraMaster as their external converter instead of DataMaster. Help › GammaVision / MAESTRO Integration… shows the exact Program and Arguments to enter in GammaVision (File › Settings › Import/Export) with Copy buttons.

$(FullName) and $(FullBase) are GammaVision macros (full path, path without extension). If a conversion fails, SpectraMaster opens its window with the input file and the error message, as DataMaster does.

5.2 Zoom, history and overview strip

  • Horizontal drag zooms to the dragged channel range (counts axis automatic); dragging a box zooms both axes.
  • Every zoom is stored in a history: Back (Backspace) and Forward (Alt+→). Reset Zoom, Home or a double click shows the full spectrum.
  • The overview strip under the plot always shows the whole spectrum: drag the blue window to pan, drag its edges to change the width, click elsewhere to jump, use the wheel to zoom.

5.3 Go to an energy or channel

Type an energy in the Go to box (Ctrl+G), e.g. 661.66, and press Enter. The unit box selects keV or channel; the width box selects ±3/5/10 FWHM (from the FWHM calibration or the detector model) or ±5…100 keV. Uncalibrated spectra accept channels only.

5.4 Counts axis and energy axis

The counts axis can be Linear, Log or √ (square root) (Ctrl+L toggles linear/log). Auto Y fits the counts axis to the visible part. Energy (Ctrl+E) switches the horizontal axis between keV and channel (keV only for calibrated spectra).

5.5 Regions of interest (ROI)

Ctrl + drag on the plot marks an ROI. The Regions of Interest panel lists start, end, centroid, energy, FWHM (channels and keV), gross and net area with ±1σ and the net count rate. The background is a straight line between the 3-channel averages at both ends. Delete an ROI with Delete in the table, from the context menu or with Clear All; Export CSV… saves the table.

5.6 Overlays

Overlay (Ctrl+Shift+O) draws other spectra — typically the background or a previous measurement — over the displayed one, each in its own colour with a legend. View › Overlays › Normalize Overlays to Live Time scales each overlay by LTdisplayed/LToverlay (the factor is shown in the legend). Overlays of different calibration are aligned in energy. Remove them one by one or all at once from the same menu.

5.7 Exporting the plot

Export (Ctrl+Shift+E) saves the current view as a PNG image or as an SVG vector drawing (for reports and publications); Ctrl+Shift+C copies it to the clipboard for Word or PowerPoint.

6. Peak search and nuclide identification

6.1 Running the analysis

Press F5 (Analyze › Peak Search & Identify) or the Analyze button. The analysis runs in the background (a few seconds for an 8k HPGe spectrum) and opens the Analysis Results panel. Analyze › Auto-analyze on Open analyses every spectrum as soon as it is opened.

6.2 The peaks table

For each peak: energy (keV), centroid (channel), FWHM (keV), net area ± 1σ, count rate (cps), significance (net area / its uncertainty) and the assigned nuclide. A double click zooms to the peak. Notes mark special peaks: X-ray region, annihilation (511 keV), single / double escape, sum peak (e.g. 1173+1332), possible backscatter.

How it works, in brief: the FWHM model comes from the FWHM calibration (or the energy calibration and a detector-type guess) and is rescaled to the strongest isolated peaks; peaks are searched with a Gaussian matched filter (second-difference method) and accepted above a significance of 3; neighbouring peaks are fitted together as multiplets (Gaussians + linear background + step), and areas and uncertainties come from the fit covariance.

6.3 The nuclides table and the confidence value

Each candidate nuclide shows its confidence, half-life, category (natural, fission, activation, calibration, medical, industrial, actinide; nuclides with two common origins show both, e.g. Cs-137 "fission / calibration"), the number of lines found / expected and a note (series membership, "typical background", interferences such as U-235 185.7 keV under Ra-226 186.2 keV). Selecting a nuclide marks all its library lines on the plot; peaks that match are highlighted.

The confidence is a heuristic score (0–100 %), not a probability. It combines how much of the expected (detectable) line pattern is explained, the energy agreement, the statistical significance, penalties for a missing strongest line or inconsistent area ratios, and a greedy treatment of shared peaks. Weak lines below the local detection limit are not counted as missing. Results — especially low-confidence ones, single-line nuclides and short-lived nuclides in old spectra — must be reviewed by an expert. The identification does not replace the laboratory's validated analysis procedure.

Peak labels (Ctrl+Shift+L) write the nuclide names on the plot; Export… in the results panel saves peaks, nuclides and spectrum details to Excel or CSV.

6.4 Uncalibrated spectra

Without an energy calibration peaks are listed by channel only and no nuclide is identified (a message explains this). Calibrate the spectrum first (chapter 7), e.g. with Eu-152 or Co-60/Cs-137 lines.

6.5 The nuclide library

The built-in library contains 200 nuclides with 2,732 gamma and X-ray lines. Values are taken from the IAEA ENSDF evaluation (IAEA ndlab database behind LiveChart of Nuclides) and cross-checked against Sandia National Laboratories' SandiaDecay. Short-lived daughters in equilibrium (Ba-137m, Pr-144, Rh-106, La-140 …) are included in the parent's intensities; natural-series members are separate entries. On the command line another library can be used: smconvert identify FILE --lib mylib.csv with lines nuclide, energy_keV, intensity_%[, half_life, category].

Limitations

  • No true-coincidence summing correction and no detailed efficiency model: the expected line ratios use a generic HPGe/NaI efficiency shape.
  • Strongly overlapping multiplets and very low-statistics spectra can give false or missed identifications.
  • Decay since the measurement is not considered: a nuclide is proposed if its lines are present, even if it is implausible for the sample history.

7. Energy recalibration and spectrum arithmetic

These tools are available on the command line (smconvert); the results are ordinary spectrum files that can be opened in the program. The input files are never modified.

7.1 Energy (and FWHM) recalibration

smconvert calibrate Eu-152.S0 --source Eu-152                 propose a calibration from source lines
smconvert calibrate *.S0 --source Co-60,Cs-137 -o D:\Recal     write recalibrated copies
smconvert calibrate X.spe --pairs 1893.7:661.66,3364:1173.23,3812:1332.49 --order 2 -o D:\Recal
smconvert calibrate X.spe --coeffs 0.12,0.3501,1.2e-8 -o D:\Recal  apply known coefficients
smconvert calibrate *.chn --source Eu-152 --only-uncalibrated -o D:\Recal

--source finds the peaks of the given nuclide(s) (using the existing calibration as a guide when present), fits an energy polynomial (order 1–3) and, from the peak widths, a FWHM calibration; it prints a table with channel, given and fitted energy and residuals (RMS and maximum). Without -o nothing is written. --fwhm ch:keV,… fits a FWHM calibration from given pairs.

Energy calibration, order 2: c0=2.85491689  c1=0.33842267  c2=-4.33136557e-08
  #     channel       given      fitted   residual
  1     351.149     121.782     121.686    +0.0957  Eu-152 121.78
  ...
RMS residual 0.0615 keV, max |residual| 0.1460 keV, 8 degree(s) of freedom

7.2 Sum of spectra

smconvert sum A.S0 B.S0 C.S0 -o SUM.spe [--align auto|channel|energy]

Counts, live and real times are added. With different calibrations the spectra are aligned in energy (rebinned onto the first spectrum's calibration); --align channel forces a channel-by-channel sum.

7.3 Background subtraction

smconvert subtract CHERN.S0 CHERNBKG.S0 -o CHERN_net.spe [--scale K] [--clip] [--sigma-csv net.csv]
net = sample - 3.31379 x background; net counts 301801 +- 1071

The background is scaled by LTsample/LTbackground unless --scale is given. --clip sets negative channels to zero; --sigma-csv also writes channel, energy, net counts and the propagated 1σ per channel.

7.4 Rebinning and truncation

smconvert rebin CHERN.S0 --factor 2 -o CHERN_4k.spe          8192 -> 4096 channels
smconvert rebin X.S0 --start 100 --stop 4196 --renumber -o part.spe

The calibration is transformed so that energies stay correct.

8. Efficiency calibration and activity

Before you start. The efficiency curve is valid only for the same detector, geometry (container, filling height, distance) and matrix density as the standard. True-coincidence summing (TCS) is not corrected (cascade emitters such as Co-60, Cs-134, Y-88, Eu-152 are flagged), and self-attenuation is corrected only by a manual factor. Results must be validated by the laboratory.

8.1 Efficiency calibration

  1. Open the standard spectrum (here QCY48CAL.S0, 10 ml bottle at 10 cm, HPGe) and choose Analyze › Efficiency Calibration…. The displayed spectrum becomes the standard (or use Browse…).
  2. Fill the certificate: one row per nuclide with activity (Bq), uncertainty %, reference date, half-life (s) and optionally the lines keV:yield% (empty = library values). Sources: Aptec records (the source records stored in Aptec .S0 files), a Preset (QCY48, QCRB1241, Eu-152 point source), Import CSV… or typing.
  3. Choose the model: two-branch log-log (recommended for HPGe: low- and high-energy branches joined at a crossover energy, automatic or fixed) or a single log-log polynomial of order 1–5. Enter geometry and detector names.
  4. Click Measure & Fit. Each line becomes a point: net area (with background-peak subtraction if a background spectrum is used in the CLI), efficiency, uncertainty, fitted value and residual. Untick Use for doubtful points (e.g. TCS-affected lines) and press Refit.
  5. Check χ²/ν and the residual plot (points should scatter within their error bars), then Save curve… The curve (JSON) is stored in %APPDATA%\SpectraMaster\efficiency\ and appears in the activity dialog.

Point efficiency: ε = N / (tlive · A(t0) · C · I), with the activity decay-corrected from the reference date to the start of counting and C the decay during counting. The curve uncertainty combines the fit covariance (scaled by χ²/ν when > 1) with the part of the certificate uncertainty common to all lines.

8.2 Activity calculation

  1. Open the sample spectrum (calibrated in energy) and choose Analyze › Activity Calculation….
  2. Select the efficiency curve. Optionally load a background spectrum: peak by peak (the background peak, scaled by live time, is subtracted from each sample peak) or full spectrum.
  3. Enter the sample quantity and unit (kg, g, L, mL) with its uncertainty, and the reference date (sampling date; default = acquisition start). All activities are decay-corrected to this date.
  4. List the nuclides of interest, choose key line or weighted mean of lines, the detection limit method (Currie or ISO 11929) and, if needed, the self-attenuation correction factor (default 1.000).
  5. Click Calculate. Export CSV/Excel… saves the table and the uncertainty budget.
Activity Bq ± uActivity with its combined standard uncertainty (k = 1).
Specific ± U (k=2)Activity per kg (or L …) with the expanded uncertainty U = 2u.
MDAMinimum detectable activity (Bq and per unit quantity), from the continuum under the expected peak (Currie: LD = k² + 2LC, k = 1.645; ISO 11929: detection limit y#).
Decisiondetected when the net signal exceeds the decision threshold (Currie LC or ISO y*); otherwise < MDA. A nuclide can be detected with an activity below its MDA (between LC and LD) — report it with its uncertainty.
BudgetRelative components (k = 1): counting, efficiency, emission probability, quantity, attenuation.

10. Archive search

File › Archive Search… (Ctrl+Shift+F) finds spectra in large archives — by sample name, words in the description, nuclides found, date, detector, folder or live time — without moving or changing the original files.

10.1 Building and updating the index

  1. Add folder… for each archive root (local disk or network share).
  2. Click Build / update index. The program lists the files, reads the metadata of every spectrum and then analyses each unique spectrum (peak search + identification) in parallel. Progress and the remaining time are shown; Cancel stops safely and the next build resumes.
  3. Later builds only process new or changed files and drop deleted ones, so updating is quick.

The index is a single SQLite file, by default %APPDATA%\SpectraMaster\archive.sqlite (Change… selects another file, e.g. a shared copy on the network). Byte-identical copies of a spectrum are recognised as duplicates and analysed once. The original files are only read.

10.2 Filters

TextWords in the sample ID, description, comments, file or folder name. All words must match.
NuclidesAdd one or more nuclides (with auto-completion: Cs-137, cs137, 137Cs are equivalent); match all of them or any of them, with a minimum confidence slider.
Date, detector, folderFrom / to date, detector name, part of the folder path.
OtherMinimum live time, calibrated spectra only, include duplicate copies.
Arabic normalisation. The text search ignores the differences أ إ آ → ا, ة → ه, ى → ي, diacritics (tashkeel) and tatweel, and treats Arabic-Indic digits like Latin digits — شاى finds شاي. The definite article is removed from the search words (also وال، بال، كال، فال، لل) when at least three letters remain, so الشاي finds شاي, الشاي and بالشاي alike.

10.3 Working with the results

Double-click a row to open the spectrum in the main window. The right-click menu offers Open in main window, Add as overlay, Open containing folder and Copy path. Columns can be sorted; the bar chart shows the results per year. Export results to Excel / CSV… saves the list with date, sample, description, nuclides, times, detector, path and number of copies.

The same index can be built from the command line for very large archives with smconvert index (Excel catalogue) — the window's index is built from the window itself.

11. Detector quality control

Tools › Detector QC… keeps control charts of the check-source and background measurements of each detector, as required by ISO/IEC 17025 (7.7). For every measurement it records the centroid energy (gain/offset drift), the FWHM (resolution), the net count rate decay-corrected to a reference date (efficiency stability), the background rate in an energy window, and live/dead time.

11.1 Creating a QC track

A track is one detector + one check source (or a background measurement). Click New… and fill in:

  • name, detector, detector type (HPGe, NaI, LaBr3, CZT), type (check source / background);
  • monitored lines — from a preset (Cs-137, Co-60, Cs-137 + Co-60, Eu-152, Ba-133, Am-241, Na-22, Background) or typed as keV[:nuclide[:FWHM max]], e.g. 661.657:Cs-137, 1332.492:Co-60:2.0;
  • reference date and reference activity (for decay correction), peak match tolerance;
  • centroid energy from each file's calibration, or a fixed reference calibration — the latter shows real gain drift even when each spectrum was recalibrated;
  • background window, baseline (first N points or a period), the Westgard rules to apply and fixed tolerances (centroid ± keV, rate ± %, background ± %).

11.2 Adding measurements

Add Files…, Add Folder… (e.g. the whole year's QC folder) or Add Displayed Spectrum. Each spectrum is analysed once and its peak list stored, so lines and tolerances can be changed later without re-reading the files; duplicates are ignored. Re-analyse re-reads all source files. In the Measurements table a right click can exclude a point from the statistics (with a note, e.g. "source repositioned"), remove it, or show the spectrum in the main window.

11.3 Control charts and Westgard rules

Mean and standard deviation are computed from the baseline points; warning limits are ±2σ and action limits ±3σ. The rules are evaluated on all non-excluded points in date order:

RuleMeaningSeverity
1-2sone point beyond ±2σwarning
1-3sone point beyond ±3σout of control
2-2stwo consecutive points beyond 2σ on the same sideout of control
R-4stwo consecutive points beyond 2σ on opposite sidesout of control
4-1sfour consecutive points beyond 1σ on the same sideout of control
10-xten consecutive points on the same side of the meanout of control
TOLfixed tolerance exceeded (centroid, FWHM max, rate, background)out of control
SPLITline found split into two peaks (gain or zero jump during the count)out of control

The Violations tab lists every rule hit with date, file, series and value; the Statistics tab gives N, mean, SD, CV % and the trend per year for each line and quantity.

11.4 Exporting and reports

Charts PNG… / SVG… save the charts, Excel… a workbook with measurements, statistics and violations, and PDF Report… a complete QC report (track settings, summary, charts, statistics, measurements, violations and a signature line) in the interface language. Tracks are stored as JSON files in %APPDATA%\SpectraMaster\qc\.

12. Troubleshooting and FAQ

The file is not recognised ("cannot recognise the format")

Check that the file is a spectrum (not a report or a calibration file) and not empty. Try File › Open Input Files As… with the expected format; the smconvert info FILE --from CODE command shows the reader's exact error. If Auto-detect is not active, a wrong fixed format is the most common cause — the status bar shows the active input mode.

Peaks are at the wrong energies

  • The file may be uncalibrated or carry an old calibration: check Energy Calibration in the information panel and recalibrate (chapter 7).
  • After conversion to CHN/CNF/SPC, read the refit warning: the deviation of the refitted calibration is printed.
  • Genie-2000 shows channel numbers one higher than SpectraMaster — energies are the same.

Arabic sample names became "????" in Genie or MAESTRO

CNF, CHN and SPC store only Latin text (section 3.4). Keep the Aptec S0, SPE, N42 or Excel file as the reference copy. Saving or converting to a format that stores only ASCII text (CHN, SPC, CNF, S100, ND66) prints a warning when the sample ID or description contains Arabic (non-ASCII) characters.

"stores only 3 calibration terms: energy calibration refitted"

Not an error: the target format cannot hold the source polynomial. Accept small deviations (≲ 0.05 keV); for larger ones choose a format that keeps the full calibration (Aptec S0, IAEA SPE, N42, JSON, Excel).

"The peak-search engine is not available" / F5 is disabled

No spectrum is open, or the spectrum is empty. Nuclides are not identified in uncalibrated spectra.

GammaVision does not call SpectraMaster

Copy Program and Arguments again from Help › GammaVision / MAESTRO Integration…; put quotes around paths with spaces when not using the macros.

Where are settings and data stored?

PreferencesLanguage, last folders, input/output formats, window layout, view options and report templates: Windows registry HKEY_CURRENT_USER\Software\SpectraMaster\SpectraMaster.
Archive index%APPDATA%\SpectraMaster\archive.sqlite (changeable in the window).
Efficiency curves%APPDATA%\SpectraMaster\efficiency\*.json
QC tracks%APPDATA%\SpectraMaster\qc\*.json

%APPDATA% is usually C:\Users\<name>\AppData\Roaming. Back up the SpectraMaster folder together with the laboratory data. Deleting the registry key resets all preferences.
